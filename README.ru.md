## Что делает программа

GameVoice RU захватывает картинку из окна **PS Remote Play** (или из видеофайла), распознаёт русские субтитры на экране и синтезирует их голосом через выбранную Bluetooth-колонку. Оригинальный английский звук остаётся на телевизоре, а русская речь звучит из колонки.

**Перевода нет** — программа читает готовые русские субтитры игры.

## Требования

### Аппаратное обеспечение

- **PlayStation 5** (для реальной игры, не обязательно для demo-режима)
- **Windows 10/11**, 64-bit
- **Bluetooth-колонка**, сопряжённая с ПК
- **Локальная сеть** (Wi-Fi или Ethernet), в которой находятся PS5 и ПК

### Программное обеспечение

- Python 3.11+ **или** собранный EXE (см. ниже)
- [PS Remote Play для Windows](https://www.playstation.com/ru-ru/remote-play/)
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) с **русским языковым пакетом**

## Установка Python-версии

### 1. Установите Tesseract OCR

Скачайте установщик UB-Mannheim:  
https://github.com/UB-Mannheim/tesseract/wiki

При установке:
- Отметьте **Russian** в разделе «Additional language data».
- Запомните путь установки (например, `C:\Program Files\Tesseract-OCR`).
- Добавьте путь в системную переменную `PATH`.

Проверьте:
```cmd
tesseract --version
tesseract --list-langs
```
В выводе должно быть `rus`.

### 2. Клонируйте репозиторий и установите зависимости

```powershell
git clone https://github.com/YOUR_REPO/gamevoice-ru.git
cd gamevoice-ru
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Установите Windows OCR (рекомендуется)

Windows OCR — встроенный движок распознавания текста, работает лучше Tesseract с игровыми шрифтами.

**Способ 1 — через настройки:**
1. `Пуск → Настройки → Время и язык → Язык`
2. Нажмите «Добавить язык» → выберите «Русский»
3. При установке отметьте «Распознавание рукописного текста»

**Способ 2 — через PowerShell (Администратор):**
```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
```

**Способ 3 — Python-пакеты WinRT (если Способ 1/2 недоступен):**
```powershell
pip install winrt-runtime winrt.windows.media.ocr winrt.windows.globalization `
            winrt.windows.graphics.imaging winrt.windows.storage.streams
```

### 4. Установите Tesseract OCR (резервный движок)

Если Windows OCR недоступен, программа использует Tesseract.

Скачайте установщик UB-Mannheim:
https://github.com/UB-Mannheim/tesseract/wiki

При установке:
- Отметьте **Russian** в разделе «Additional language data».
- Добавьте путь установки в системную переменную `PATH`.

Проверьте:
```cmd
tesseract --version
tesseract --list-langs   # должно содержать "rus"
```

### 5. Скачайте голосовые модели Piper

```powershell
python -m gamevoice_ru.pipeline.tts --download piper
```

Это скачает два голоса (~65 МБ каждый) в `%USERPROFILE%\.gamevoice_ru\voices\`.

Лицензия голосов: **CC0-1.0** (Creative Commons Zero — общественное достояние).

### 6. Запустите приложение

```powershell
python -m gamevoice_ru
```

## Установка собранного EXE

1. Скачайте `GameVoiceRU-windows-x64.zip` из раздела [Releases](../../releases) или [Actions artifacts](../../actions).
2. Распакуйте в любую папку (например, `C:\GameVoiceRU`).
3. Запустите `GameVoiceRU.exe`.
4. При первом запуске автоматически откроется мастер настройки.

> **Примечание:** EXE не включает голосовые модели. При первом запуске нажмите кнопку «Скачать модели» в настройках TTS.

## Настройка PS Remote Play

### Схема подключения

```
PS5 ─── HDMI ───> Телевизор  (изображение + оригинальный звук)
 │
 └── Remote Play (Wi-Fi/Ethernet) ──> ПК  ──> GameVoice RU ──> Bluetooth-колонка
```

### Два PSN-аккаунта (рекомендуемый сценарий)

Это **неофициальный**, но подтверждённый пользователями трюк:

1. **Основной аккаунт** (ваш игровой) — подключён напрямую к PS5.
2. **Дополнительный аккаунт PSN** — создайте бесплатный на сайте PlayStation.
3. Включите Remote Play на PS5: `Настройки → Система → Remote Play`.
4. Запустите «PS Remote Play» на ПК, войдите со **вторым аккаунтом**.
5. Настройте качество потока: 720p или 1080p, 30/60 кадр/с.
6. **Уменьшите громкость** звука в Remote Play до нуля — это предотвратит дублирование звука из колонки.

> ⚠️ **Важно:** Sony официально не поддерживает одновременную игру на основном аккаунте и Remote Play на дополнительном. Работоспособность зависит от вашей конфигурации сети и версии прошивки PS5.

### Включите субтитры в GTA VI

- Меню игры → `Настройки → Доступность → Субтитры → Включить`.
- Убедитесь, что выбран **русский язык** субтитров.

## Сопряжение Bluetooth-колонки

1. Включите колонку в режим сопряжения.
2. `Пуск → Настройки → Bluetooth и устройства → Добавить устройство`.
3. Выберите колонку из списка.
4. После подключения колонка появится в списке в GameVoice RU.

## Первый запуск и настройка

При первом запуске откроется мастер из 5 шагов:

### Шаг 1: Выбор источника видео

- **Remote Play** — выберите, если уже запустили «PS Remote Play».
- **Файл/папка** — для demo-режима без PS5.

### Шаг 2: Выбор области субтитров

Нажмите **«Выбрать область субтитров»** и введите координаты прямоугольника.

> Если оставить нули, программа автоматически захватывает нижние 27% экрана — стандартная зона субтитров для большинства игр.

### Шаг 3: Выбор Bluetooth-колонки

Выпадающий список **«Аудиовыход»** покажет все устройства. Выберите свою колонку.

### Шаг 4: Проверка звука

Нажмите **«Тест звука»** — программа произнесёт тестовую фразу. Если слышно из колонки — всё настроено.

### Шаг 5: Запуск

Нажмите **«▶ Начать озвучку»**.

## Загрузка голосовых моделей

Программа использует **Piper TTS** с двумя русскими голосами:

| Голос | Пол | Лицензия |
|---|---|---|
| Дмитрий (`ru_RU-dmitri-medium`) | Мужской | CC0-1.0 (свободное использование) |
| Ирина (`ru_RU-irina-medium`) | Женский | CC0-1.0 (свободное использование) |

Скачать из командной строки:
```powershell
python -m gamevoice_ru.pipeline.tts --download piper
```

Или нажать кнопку **«Скачать голоса»** в интерфейсе программы.

Модели сохраняются в `%USERPROFILE%\.gamevoice_ru\voices\` (~60–80 МБ каждая).

## Demo-режим

Позволяет проверить всю цепочку **без PS5**:

1. Запустите генератор тестовых кадров:
   ```powershell
   python test_data/generate_frames.py
   ```
2. В приложении выберите **«Тип источника → Файл/папка»**.
3. Укажите путь к папке `test_data/frames/`.
4. Нажмите **«Начать озвучку»**.

Программа пройдётся по синтетическим кадрам с русскими субтитрами, распознает их и произнесёт вслух.

## Часто задаваемые вопросы

**В: Программа показывает «Окно Remote Play не найдено».**  
О: Убедитесь, что приложение PS Remote Play запущено и подключено к PS5. Если окно свёрнуто — разверните его.

**В: Текст не распознаётся / OCR пустой.**  
О: Проверьте установку Tesseract (`tesseract --list-langs` должно содержать `rus`). Настройте область субтитров вручную.

**В: Голос не звучит / нет звука из колонки.**  
О: Проверьте, что колонка выбрана в выпадающем списке. Нажмите «Тест звука». Убедитесь, что голосовые модели скачаны.

**В: Одна фраза произносится несколько раз.**  
О: Увеличьте «Время подтверждения» (settle_ms) в настройках.

**В: Задержка между субтитром и голосом слишком большая.**  
О: Нормальна задержка Remote Play (100–200 мс) + задержка Bluetooth (50–150 мс) + синтез (~500 мс). Итого: 0.7–2 с. Уменьшить не всегда возможно без деградации качества.

## Известные ограничения

| Ограничение | Статус |
|---|---|
| Захват PS5 через Remote Play не тестировался на реальном железе в этой сборке | ⚠️ Требует проверки пользователем |
| Bluetooth-синхронизация с телевизором невозможна (задержка Bluetooth ~100-300 мс) | ✓ Задокументировано |
| Свёрнутое окно Remote Play → захват прекращается | ✓ Программа предупреждает |
| Некоторые игры блокируют Remote Play через HDCP | ✓ Программа не обходит защиту |
| Второй PSN-аккаунт для Remote Play — неофициальная схема | ⚠️ Может не работать |
| macOS и Linux не являются целевыми платформами | ℹ️ P2 |
