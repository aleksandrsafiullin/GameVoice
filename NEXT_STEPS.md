# NEXT_STEPS.md — Приоритеты после MVP

## P0 — Критические для первого реального использования

1. **Реальный тест с PS5 + Remote Play**  
   Проверить захват окна Remote Play на Windows 11, убедиться что субтитры GTA VI попадают в выбранную область и OCR их распознаёт.

2. **Загрузчик голосовых моделей в GUI**  
   Кнопка «Скачать голоса» с прогресс-баром прямо в настройках, без командной строки.

3. **Уточнение области субтитров**  
   Реализовать полноэкранный оверлей для рисования прямоугольника мышью (на Windows через transparent tkinter Toplevel или win32api).

4. **Windows OCR (WinRT) тестирование**  
   Проверить `WindowsOCR` на Windows 11 с русским языковым пакетом. Возможно, точнее Tesseract для игровых шрифтов.

5. **Расширенный тест OCR на реальных субтитрах GTA VI**  
   Снять скриншоты субтитров → прогнать через OCR → измерить точность → настроить препроцессинг.

## P1 — Улучшения качества

6. **Профили игр**  
   Пресеты под конкретные игры: GTA VI, RDR2, Cyberpunk 2077. Каждый профиль хранит координаты области, цвет текста, настройки стабилизатора.

7. **Улучшенный препроцессинг OCR**  
   Тестировать на реальных кадрах: dark outline subtitles, тени, динамический фон, желтые/белые буквы на светлом фоне.

8. **Несколько голосов по имени персонажа**  
   Если субтитры содержат префикс имени (например, «Линкольн: Привет»), назначать разные голоса разным персонажам.

9. **Автоопределение потери источника**  
   При потере Remote Play автоматически пытаться переподключиться каждые 5 секунд.

10. **Статистика задержек в GUI**  
    Показывать в реальном времени: OCR latency, TTS latency, queue wait, estimated audio start.

## P2 — Долгосрочные улучшения

11. **Silero TTS в GUI**  
    Удобная кнопка установки Silero (требует PyTorch ~2 ГБ). Пометить лицензию CC-BY 4.0.

12. **Горячая клавиша Stop/Resume**  
    Глобальный хоткей (Ctrl+Shift+G) для паузы/возобновления озвучки без переключения окна.

13. **Работа в трее**  
    Свернуть в системный трей, управление через контекстное меню.

14. **Экспорт субтитров в SRT**  
    Сохранять распознанные субтитры с временными метками в SRT-файл для последующего редактирования.

15. **macOS / Linux поддержка**  
    Захват экрана через mss уже кросс-платформенный. Нужно: тест Piper на mac, pkgs для macOS.

16. **Прямой перевод английских субтитров**  
    Если русских субтитров нет или OCR пустой — добавить опциональный путь: English OCR → NLLB перевод → Russian TTS.
